# 시장·제도 조사

## STO 제도 환경

토큰증권은 단순 가상자산이 아니라 자본시장법상 증권에 해당하는 권리를 분산원장 기술로 기록·관리하는 구조입니다. 따라서 실제 수익 배분권, 배당권, 투자계약증권 구조가 포함되면 증권 규제 검토가 필요합니다.

## 프로젝트 적용 방향

Hotel STO Lab은 실제 발행·청약·유통을 제공하지 않고, 교육용 계산 구조로 한정합니다.

| 구분 | 실제 STO 플랫폼 | Hotel STO Lab |
|---|---|---|
| 투자금 | 실제 입금 | 모의 투자금 |
| 증권 발행 | 있음 | 없음 |
| 토큰 발행 | 실제 기록 | 가상 수량 계산 |
| 배당 | 실제 지급 | 계산 결과 표시 |
| 목적 | 자금 조달·투자 | 금융교육·시뮬레이션 |

## 왜 호텔인가

- 수익구조가 명확합니다.
- 점유율, ADR, 운영비 변수가 직관적입니다.
- 지역 관광자산과 연결하기 좋습니다.
- 자산금융과 배당구조를 설명하기 좋습니다.
