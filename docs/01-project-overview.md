# 프로젝트 개요

## 프로젝트명

Hotel STO Lab

## 한 줄 설명

호텔 객실 운영 수익을 기반으로 토큰증권 투자 수익률과 배당 구조를 학습하는 금융교육형 시뮬레이션 플랫폼

## 목적

복잡한 STO, 조각투자, 투자계약증권, 배당가능이익, 수익률 변동 개념을 호텔 객실 운영 수익이라는 직관적인 사례로 설명합니다.

## 주요 사용자

| 사용자 | 목적 |
|---|---|
| 금융 초보자 | STO와 배당 구조 학습 |
| 금융 DT 학습자 | 자산 기반 금융 서비스 구조 이해 |
| 호텔·관광 전공자 | 호텔 운영 수익과 투자 구조 연결 |
| 핀테크 포트폴리오 준비자 | 금융 시뮬레이션 서비스 구현 사례 확보 |
| 직업훈련 학습자 | 데이터 기반 금융교육 MVP 실습 |

## 핵심 기능

- 호텔 프로젝트 선택
- 호텔 수익 계산
- 운영비 차감
- 배당가능이익 계산
- 토큰 보유비율 계산
- 배당금 계산
- 수익률 시각화
- 리스크 이벤트 시뮬레이션
