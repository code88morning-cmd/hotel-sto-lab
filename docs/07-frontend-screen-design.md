# Frontend Screen Design

## 화면 구조

```text
Home Dashboard
├─ Header / Navigation
├─ Project Summary Section
├─ Hotel Project Selection
├─ Revenue Simulation Panel
├─ Token Offering Simulation Panel
├─ Dividend Result Section
├─ Monthly Dividend Chart
├─ Risk Event Section
├─ Learning Guide Section
└─ Compliance Notice Footer
```

## 핵심 화면 요소

| 영역 | 설명 |
|---|---|
| KPI Cards | 객실매출, 배당가능이익, 내 배당금, ROI |
| Hotel Cards | 호텔 프로젝트 선택 |
| Simulator Panel | 점유율, ADR, 운영비율, 투자금 조정 |
| Dividend Result | 예상 배당금 및 월 수익률 표시 |
| Risk Event | 이벤트 적용 전/후 비교 |

## UI 톤

- 네이비 + 골드 + 아이보리
- 프리미엄 호텔 금융 대시보드
- 실제 투자처럼 보이는 청약/매수 UI 제외
